# Code of Conduct

## Our Standard

EasyABNT is a technical project for academic writing tooling. Contributions should keep discussions factual, respectful, and focused on improving the project.

Expected behavior:

- Use respectful language in issues, pull requests, reviews, and discussions.
- Critique ideas, code, documentation, and decisions without attacking people.
- Assume good intent, but ask for clarification when something is ambiguous.
- Keep feedback specific, actionable, and relevant to the project.
- Respect different levels of experience with ABNT, academic writing, Git, and plugin development.

Unacceptable behavior:

- Harassment, insults, intimidation, or discriminatory language.
- Personal attacks, trolling, or repeated off-topic disruption.
- Publishing private information without explicit permission.
- Deliberately misleading users about ABNT rules, institutional requirements, licensing, or project status.
- Using project spaces for spam, unrelated promotion, or abusive automation.

## Academic Integrity

This project must support responsible academic work. Contributors should not add features or documentation that encourage plagiarism, fabricated citations, fake references, or misrepresentation of authorship.

When implementing document-generation behavior, prefer explicit placeholders and source validation over invented data.

## Enforcement

Maintainers may moderate, edit, hide, or remove contributions that violate this code. Repeated or severe violations may lead to temporary or permanent restrictions from project spaces.

If you need to report a concern, open a private communication channel with a maintainer when available. If no private channel exists yet, create a GitHub issue with only the minimum public context needed and ask for maintainer contact.

## Scope

This code applies to all official project spaces, including the repository, issues, pull requests, discussions, documentation, examples, and community channels managed by the project.
